GFOpenSoundCraft 0.1.0 native qualification build for AmigaOS 3.x
=================================================================

STATUS: NATIVE WINDOW QUALIFICATION BUILD; NOT A RELEASE CANDIDATE. Native
startup, GFOpenSynth open/reset/message/close, GFOpenLayout rendering, bounded
control events and clean exit passed in an isolated 68040 lab on 21 November
2026. Timed transport playback and file I/O remain release gates.

Requirements
------------
- AmigaOS 3.x
- 68040 CPU
- gfopensynth.library version 1 or newer

Included
--------
- native Amiga Hunk executable
- bounded session and MIDI sequence models
- GFOpenSynth reset, note-on, note-off and all-notes-off smoke path
- native GFOpenLayout editor with track, timeline and inspector panels
- working Play note, Stop and MIDI record-arm controls

The Play note control sends a bounded C4 note-on/note-off pair immediately;
it is not timed transport playback. Add MIDI track is visibly marked as the
next slice and disabled. Audio clips, save/load, SMF, AHI recording/rendering
and CAMD device I/O are not claimed.
