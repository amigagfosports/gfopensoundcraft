GFOpenSoundCraft 0.1.0 RC1
==========================

This is the first distributable native AmigaOS 3.x 68040 release candidate for
SoundCraft's compact MIDI-sequencer path. It is intended for final external
audio UAT, not presented as the full desktop SoundCraft application.

Working in this build:
- native GFOpenLayout transport, track, timeline and inspector interface;
- bounded session and 960 PPQ MIDI models;
- Play audition and Stop/reset through GFOpenSynth and AkikoPlus OpenSynth;
- MIDI record-arm state;
- bounded SCF1 Save and Open at PROGDIR:SoundCraft.scf;
- stable track IDs, track mix state, notes and controller events in SCF1;
- fail-closed parsing for truncated, malformed, over-limit and trailing data.
- generated Installer and application/drawer/ReadMe GlowIcons.

Not yet qualified:
- timed transport and editing beyond the supplied sequence;
- CAMD device recording;
- AHI audio recording, mixing and rendering;
- desktop SoundCraft project compatibility;
- ASL file requesters and GFOpenUp installation;
- audible output outside the muted qualification lab.

Verified for this exact candidate:
- exact-head LumaVAULT Kitchen tests, clippy, native compile and LhA packaging;
- byte-verified local UAT2 LhA package;
- native 68040/FPU window, MIDI arm, save, reopen and clean close;
- rejection of a three-byte hostile project without replacing live state;
- graceful editing when gfopensynth.library is absent;
- synth-present startup and GFOpenSynth note/reset message delivery;
- Installer 47.19 Pretend, fresh install and project-preserving update paths.

Final release still requires audible output proof outside the muted lab. RC1
exists so that check can be performed on an unmuted Amiga system. See
`evidence/native-68040-uat1-20261122.txt` for the full pre-RC native receipt.
